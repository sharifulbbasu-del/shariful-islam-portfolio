# Md. Shariful Islam | Production Management Portfolio

A responsive personal portfolio website created from the supplied CV.

## Features
- Responsive layout for desktop and mobile
- Career experience timeline
- Skills and achievement highlights
- Education and training section
- Email and phone contact links
- No frameworks or build tools required

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub, for example `shariful-islam-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages section will show the public URL.

## Before publishing
- Review the phone number and email address shown in `index.html`.
- Remove any personal information you do not want public.
- Add your LinkedIn profile URL if you want to include it.
- The achievement figures and career details are based on the supplied CV and have not been independently verified.

## Files
- `index.html` — website content
- `style.css` — layout and visual design
- `script.js` — mobile navigation and current year
